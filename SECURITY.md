# Security

> **These contracts are unaudited.** Do not deploy to mainnet or use with real
> funds. Intended for local and testnet development only.

The full threat model, trust boundaries, known limitations, and
responsible-disclosure instructions live in [`docs/SECURITY.md`](docs/SECURITY.md).

**To report a vulnerability:** open a private GitHub Security Advisory
(Security → Advisories → Report a vulnerability) rather than a public issue.
